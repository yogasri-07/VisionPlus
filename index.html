VISIONPLUS

Explainable AI for Diabetic Retinopathy Screening

VisionPlus is an AI-assisted retinal screening application designed to support diabetic retinopathy assessment from retinal fundus images. It combines image-quality assessment, deep-learning-based DR grading, retinal vessel analysis, and Grad-CAM explainability.

View Screening Workflow

Key Features

Image Quality Assessment

Evaluates focus, illumination, field of view, and overall image quality before screening.

DR Grading

Performs five-class diabetic retinopathy grading from Grade 0 to Grade 4 using deep learning.

Grad-CAM Explainability

Generates visual explanations showing regions contributing to the model prediction.

Retinal Vessel Analysis

Uses U-Net-based segmentation for retinal vessel analysis and supporting image interpretation.

Screening Report

Provides structured screening results including quality, grade, confidence, referral indication, and recommendations.

Rural Screening Support

Designed with resource-constrained and community screening environments in mind.

System Workflow

VisionPlus follows an explainable AI screening pipeline from retinal image acquisition to screening report.

Fundus Image → Quality Assessment → Preprocessing → DR Grading → Grad-CAM → Screening Report

AI & Technology

ResNet18

Deep-learning model used for five-class diabetic retinopathy classification.

U-Net

Segmentation architecture used for retinal vessel analysis.

Grad-CAM

Explainable AI method used to visualize regions influencing the model prediction.

MATLAB

Development and deployment environment used for the VisionPlus application.

Diabetic Retinopathy Grading

VisionPlus uses a five-grade classification workflow.

Grade Description
0 No DR
1 Mild DR
2 Moderate DR
3 Severe DR
4 Proliferative DR

Datasets

The development workflow uses publicly available retinal imaging datasets for classification and segmentation tasks.

DRIVE

Used for retinal vessel segmentation development.
